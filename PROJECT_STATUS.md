# OpenX: состояние проекта и дальнейший путь

Актуально на 10 августа 2026 года.

## Назначение

OpenX — самостоятельный Electron-клиент для уже работающего OpenClaw Gateway. Клиент не запускает и не контролирует локальный процесс Gateway. Electron Main владеет удалённым соединением, typed host-api отделяет Renderer от транспорта, а ACP-мост сохраняет штатный чат-протокол OpenClaw.

## Добавлено

- Подключение к удалённому `ws://`/`wss://` Gateway с token- и password-авторизацией.
- Хранение секрета в Electron `safeStorage`, без передачи открытого значения в Renderer.
- Автопереподключение с backoff и отдельные состояния: ошибка авторизации, недоступный адрес, переподключение.
- Постоянная регистрация OpenX как ограниченного OpenClaw Node после основного подключения.
- Удалённые сессии OpenClaw, включая сессии вне локальных проектов.
- Дерево «Проекты -> вложенные папки -> чаты» и отдельная секция закреплённых элементов.
- Персистентные порядок, сворачивание, переименование, закрепление и drag-and-drop.
- Синхронизация имени, категории и рабочей директории чата с OpenClaw.
- Автоматические отображаемые имена моделей, совместимость Gemini Low/Max и скрытие неподдерживаемого Thinking.
- Память выбора модели и Thinking по сессии, пользовательские пресеты и статистика осознанных выборов.
- Индикатор заполнения контекста с раскрываемой панелью статистики запроса.
- Навигатор по пользовательским сообщениям с анимацией и превью вопроса/ответа.
- Системная шапка окна OpenX, поиск чатов по `Ctrl+K`, контекстные меню и единый диалог удаления.
- Открытие локального терминала в директории проекта или папки.
- Нижнее меню прогресса агента: компактный индикатор «Шаг N/M» раскрывает реальные ACP-этапы и их состояния.

## Изменено

- Бренд, package-id, внутренние ключи, preload API, переменные окружения, плагины, документация и тестовые фикстуры переименованы из старого имени в OpenX.
- Старый workspace-first сайдбар полностью заменён проектной моделью.
- Cron, Channels, Skills, Agents, Models и конфигурация переведены на удалённый Gateway; локальная имитация работы без соединения не используется.
- Закреплённый чат или проект показывается только в секции «Закреплённые», без дубликата в исходной секции.
- При переносе чата в папку меняется `cwd` удалённой сессии; при возврате в общий список восстанавливается workspace по умолчанию.
- Область чата визуально отделена от chrome и инструментов, при этом исходный стиль приложения сохранён.
- Выделение и копирование запрещены в chrome приложения; текст остаётся доступен для выделения внутри содержимого чата и полей ввода.

## Удалено

- Spawn, supervisor, restart governor, startup recovery и другие части локального lifecycle Gateway.
- Устаревшие тесты и harness-сценарии, проверявшие запуск и восстановление локального Gateway.
- Старое имя продукта во всех отслеживаемых текстовых файлах и именах ресурсов.
- Текущая иконка приложения, favicon и tray-иконка. До появления нового брендинга сборка использует нейтральную системную иконку Electron и не создаёт tray.
- Старые inline-карточки плана в ленте: прогресс теперь собран в одном нижнем меню.

## Ограничения текущего этапа

- Новый комплект иконок и tray-поведение ещё не спроектированы.
- Встроенный терминал пока является первым этапом: клиент открывает системный терминал в нужной локальной папке, но не предоставляет полноценную PTY-панель.
- Команды OpenX Node намеренно ограничены объявленным allowlist. Произвольный удалённый shell не предоставляется.
- Лимиты провайдера показываются только тогда, когда Gateway/провайдер передаёт реальные metadata; неизвестные значения не синтезируются.
- Локальный путь проекта имеет смысл только на компьютере, где запущен OpenX. Для Gateway на другом компьютере требуется явное сопоставление локального и удалённого пути.
- До выпуска новой иконки закрытие окна оставляет Node активным в фоне; повторный запуск OpenX поднимает существующее окно.

## Дальнейший путь

### 1. Надёжность подключения

- Экран диагностики handshake: URL, Origin, режим auth, pairing и последняя причина разрыва без раскрытия секрета.
- Управляемое переподключение и ручная повторная авторизация без перезапуска приложения.
- Матрица совместимости с поддерживаемыми версиями протокола OpenClaw.

### 2. Удобство проектов и чатов

- Undo для перемещения, закрепления и удаления организационных записей.
- Массовое выделение и перенос чатов.
- Явное сопоставление local path <-> remote Gateway path для разнесённых машин.
- Экспорт/импорт структуры проектов без секретов.

### 3. Управление клиентом агентами

- Версионированный контракт `openx.*`, аудит вызовов и подтверждение чувствительных действий.
- События Node о смене активного проекта, сессии и рабочей директории.
- Capability negotiation, чтобы агент видел только реально поддерживаемые команды клиента.

### 4. Терминал

- Встроенная PTY-панель с вкладками, resize, безопасным cwd и восстановлением сессии.
- Разделение локального терминала OpenX и удалённого terminal tool OpenClaw.
- Настраиваемые политики подтверждения команд.

### 5. Модели и наблюдаемость

- Унифицированная таблица provider metadata: context window, Thinking, стоимость и rate limits.
- История заполнения контекста и предупреждения до compaction.
- Диагностический экспорт без токенов, паролей и содержимого приватных сообщений.

### 6. Подготовка выпуска

- Новый нейтральный набор иконок для Windows/macOS/Linux и tray.
- Проверка keyboard navigation, screen reader и контрастности обеих тем.
- Подписанные пакеты, миграционные тесты пользовательского хранилища и rollback обновления.
